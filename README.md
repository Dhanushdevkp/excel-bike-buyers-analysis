# Bike Buyers Analysis Dashboard

## Overview
This project focuses on analyzing customer demographics and identifying patterns that influence bike purchase decisions using Microsoft Excel.

## Dataset
The dataset contains customer information including:
- Gender
- Marital Status
- Occupation
- Age
- Income
- Region
- Bike purchased

## Tools Used
- Microsoft Excel

## Data Analysis Performed
- Cleaned and prepared the dataset
- Analyzed customer demographics
- Created Pivot Tables for analysis
- Created charts and visualizations
- Used Slicers for interactive filtering
- Built an interactive dashboard to understand bike purchase patterns

## Key Insights
- Analyzed factors affecting bike purchase decisions
- Compared bike buyers based on demographics and income
- Identified customer segments with higher purchase rates

## Project File
- `Bike_Buyers_Analysis_Dashboard.xlsx` - Excel workbook containing the analysis and dashboard

## Conclusion
This project helped me improve my Excel data analysis skills, including data cleaning, Pivot Tables, Slicers, visualization, and dashboard creation.
